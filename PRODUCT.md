# Copiloto PR Reviewer

## Users
Software engineers who use Claude Code and want voice feedback + an easy way to review GitHub PRs with local LLM assistance.

## Product Purpose
A desktop companion app that:
1. Provides text-to-speech for Claude Code responses (existing Copiloto)
2. Offers a floating chat widget for reviewing GitHub PRs using local Ollama models

## Tone
Professional, maritime, reliable. Like a ship's bridge — clean instruments, clear signals.

## Register
product

## Strategic Principles
- Stay lightweight — this is a companion, not an IDE
- Respect the user's workspace — floating widget, never modal
- Offline-first where possible — Ollama runs locally

## Anti-References
- Don't look like a generic chat app (no bubbly messages, no gradients)
- Don't use purple AI branding
